# Visual assets

- `banner.png`: original image generated for this repository; the prompt is recorded in `banner-prompt.md`.
- `banner.gif`: the animated banner at the top of the README. It keeps the illustration of `banner.png`, sets the title in the project page's type, and plays the page's title and banner animations once before a four-second rest. Every frame is drawn from code; no image was generated for it.
- `roadmap.png`: the survey's overview figure (Figure 1), exported from the manuscript. Update it when the manuscript figure changes.
- `icons/*.svg`: original section icons that share one outline style and palette.

The reference repositories inspired the presentation; their illustrations and icons were not copied.
